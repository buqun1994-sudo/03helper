## 本轮事实来源与状态

1. “助手本体单独下载、避免自有服务器 600GB/月安装包直链”来自本轮产品输入；分发源经用户真实安卓手机验证和确认定稿为“每个组件一个无密码蓝奏云 ZIP 分享页作为国内自动主源、R2 / GitHub Releases 镜像同一 ZIP 自动备用、密码文件夹和三应用合并 ZIP 仅人工 / 离线兜底”，目前只写入方案，不代表源站或客户端已经上线。
2. 用户提供的 ZIP 测试页为 `https://wwatl.lanzouw.com/icExq435o4sj`、`https://wwatl.lanzouw.com/i9neI435o4zg`、`https://wwatl.lanzouw.com/iGrHV435o5ah`；组件映射尚未冻结，禁止凭顺序猜测产品身份。
3. 用户已在真实安卓手机上确认 ZIP 分享页下载并解压顺利；F2 本地隐藏 WebView 回调、ZIP 校验、唯一 APK 解压和删除 owner 已施工，真实 Android System WebView 与网络闭环仍待用户人工验证。
4. `S56_HQX`、Android 9、TCP `5555` 常驻开放和 `ro.adb.secure=0` 是当前样本设备的实测事实；它们仅支撑适配和验证计划，不能被复制成通用兼容承诺。
5. “首次连接前不承诺自动打开无线调试”“OTG 暂不入正式主链”“远端清单不得下发任意 shell”“授权读原值、幂等追加、回读”是本轮确定的架构 / 安全不变量。
6. 03桌面长期 Release 签名、03 歌词 production 发布身份、文件管理器 Debug / GPL 状态是当前发布阻断事实；在对应证据完成前，不得把组件列为正式公开发布物。
7. Cloud 仓库的官网、release index、R2、GitHub Releases、API 和产品目录是 03helper 可接入能力，不是 03helper 已部署的服务；任何 Android ZIP 清单、R2 对象或 Cloud API 接线都要另行施工和验证。
8. F1 已在上述 Android 工程锚点内落地唯一 `InstallationSession`、结构化 command / event、检查点与证据快照；生产入口和 Debug 场景均复用该 owner。该事实不代表真实下载、设备发现、ADB、授权或车机安装已经接入。
