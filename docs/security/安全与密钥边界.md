# 安全与密钥边界

## 1. 密钥和配置

1. 真实签名文件、私钥、密码、token、生产配置、设备地址和个人绝对路径不得进入 Git。
2. 客户端可公开的版本清单、公钥摘要和兼容元数据与服务端机密分开维护；客户端不保存发布私钥。
3. `.codex/local-context.properties`、`local.properties`、`keystore.properties` 和构建产物必须被忽略；提交前执行秘密扫描和 `git diff --check`。
4. 03helper 自身的签名身份、组件清单签名身份、03 歌词 production 身份和 03桌面 Release 身份必须分离管理；任何一个身份尚未建立，都不能用 Debug 包冒充正式信任根。

## 2. 下载与安装供应链

1. 首版主方案是“助手本体单独分发，组件 ZIP 延迟下载”：每个组件使用无密码单组件 ZIP 蓝奏云分享页作为国内自动主源，Cloudflare R2 与 GitHub Releases 镜像同一 ZIP 并依次自动兜底，客户端依据签名版本清单完成 ZIP 与 APK 双重校验后再安装。
2. 蓝奏云只允许安装助手自己的隐藏 Android System WebView 适配器访问固定的无密码单组件 ZIP 官方分享地址；不调用第三方“直链转换器”，不打开外部浏览器，也不把页面内容或最终地址展示给用户。密码聚合文件夹、三应用合并 ZIP 与夸克仅用于人工或离线交付。
3. 下载只接受 HTTPS 和受信任清单；必须校验清单签名、ZIP 文件大小与 SHA-256、APK entry 名称、APK 大小与 SHA-256、包名、签名证书摘要、版本和兼容范围。自有服务器每月 600GB 流量不作为安装包直链主预算。
4. 清单只能携带已审查发布物、固定的无密码单组件 ZIP 蓝奏云分享地址、R2 / GitHub ZIP 对象地址和兼容元数据，不能携带任意 shell、脚本、动态权限或未审查 URL；源切换只能由固定的蓝奏云 → R2 → GitHub Releases 策略触发。
5. ZIP 必须完整下载并校验后才能解压；解压必须只产生清单指定的唯一 APK。APK 完成大小、哈希、包身份和证书校验后，才允许向车机做非流式推送；成功解压后立即删除 ZIP，失败、取消或过期文件按生命周期清理。
6. 校验失败、签名不一致、版本回退、清单过期、源不可达或包身份不符时 fail closed，并向用户给出可理解的下一步。

### 蓝奏云 ZIP 特殊边界

1. 无密码单组件 ZIP 蓝奏云分享地址指向网页，不等于 ZIP 对象地址；客户端在安装进度页背后用 Android System WebView 执行官方手机页面，在下载回调中取得最终 URL，再交给应用自有原生下载器，不手工复刻隐藏字段或依赖第三方服务。
2. WebView 使用默认手机端标识，不改成桌面 User-Agent；不暴露应用 JavaScript bridge、设备文件或 ADB 能力。解析超时、未触发下载、最终响应为 HTML / JSON 或域名不在适配器允许范围时，立即改走 R2。
3. 最终 ZIP 响应仍必须经过 HTTPS、大小上限、超时 / 取消、清单签名、ZIP SHA-256 和归档结构校验；解压出的 APK 还必须通过 APK SHA-256、包身份和证书校验。蓝奏云不成为唯一源，页面改版或限流只应触发自动降级。
4. 用户已用真实安卓手机验证无密码 ZIP 分享页的下载与解压体验顺利；三个测试链接均已提供，但不能据此猜测每个链接的组件映射或声称三者都已逐个验证。该证据不等于安装助手内的 WebView 自动回调已经实现，应用内自动闭环仍需施工与运行级验证。

## 3. ADB 与系统授权

1. ADB 命令使用版本化白名单和参数 schema；不提供默认任意 shell 入口，也不让远端清单下发命令文本。
2. 写入系统设置前读取原值，按白名单幂等追加，执行后回读并比较；未知值不覆盖，失败不静默，不删除车机已有通知或无障碍服务授权。
3. 首次连接前不承诺自动打开无线调试。当前样本 `S56_HQX` 为 Android 9、TCP `5555` 常驻开放且 `ro.adb.secure=0`，仅作为已测设备事实，不能当作通用安全或兼容承诺。
4. 新增 Android 权限、无障碍服务、文件访问或网络域名必须记录用户价值、版本边界、最小权限、拒绝后的功能退化和运行验证，不能因为“安装更方便”无限扩大权限。

## 4. 数据与日志

1. 只收集完成安装所需的最少设备信息；不读取媒体、通讯录、车辆控制数据或无关文件。
2. 日志只记录阶段、错误类别、非敏感设备标识和版本；诊断导出由用户主动触发并默认脱敏。
3. 不保存完整 shell 历史、私钥或可重放的授权令牌；缓存和临时 APK 按生命周期清理。

## 5. 高风险动作

清除数据、卸载、降级、重启、修改签名、发布、切换生产下载源和公开切换版本清单都必须取得用户当次明确授权；普通 debug 安装和最简 smoke 不自动扩大到这些动作。

## 6. 发布阻断

1. 03桌面尚无长期 Release 签名，不能进入正式分发清单。
2. 03 歌词尚未建立 production 发布身份，不能以当前开发包作为公开升级根。
3. 文件管理器仍为 Debug 身份，且正式分发需履行 GPL 义务；在身份和义务未完成前只能保留为待审核可选项。
