# 设计规则

1. 触发条件：首次打开安装助手。动作：使用整屏浅蓝背景与白色标题、说明、步骤、状态和进度，只围绕“发现设备、快速读取应用列表、选择组件、开始下载并安装、查看结果”组织；不在首屏展示维护工具噪音。验证：新用户从冷启动到完成的运行级 smoke。边界：不退回浅灰页面、大面积白底工作区或内部 ADB 术语。
2. 触发条件：安装完成进入维护态。动作：保留蓝色背景，把重新安装、检查更新、修复授权、诊断导出和受控应用等动作做成大号、极简、按用途分组的分类按钮；破坏性动作单独确认并说明影响。验证：维护态网格、进入 / 按压 / 退出动画、确认、取消和返回。边界：不使用小型白底工具列表，不把一键清理设计成默认清空数据。
3. 触发条件：新增用户可见状态。动作：用用户能理解的任务、结果和下一步表达，补齐空态、加载态、失败态、权限态和离线态。验证：真实分辨率截图或设备 smoke。边界：不在界面解释内部实现、调试参数或秘密。
4. 触发条件：页面、按钮、加载、进度或结果发生任何用户可见变化。动作：必须复用 `FastOutSlowInEasing` 令牌完成进入、退出、出现、消失、按压和数值追随动画；长流程支持中断和恢复。验证：可控时钟中间帧、真实设备逐帧观察和无障碍操作。边界：禁止静态突变、实时模糊、持续截图、弹跳和高频装饰动画。
5. 触发条件：文案或图标表达不清。动作：使用熟悉的图标和短动作词，必要时提供悬停 / 辅助说明；按钮尺寸稳定，长文本不得溢出。验证：窄屏、字体放大和错误信息截图。边界：不使用营销式说明代替实际操作入口。
6. 触发条件：首次安装或维护态界面新增、重排或换肤。动作：复用 Cloud 最新 iCAR 03 官网的平面分区、细边框、克制留白和清晰图标；再按 03helper 自身令牌落成蓝底白字首次安装态与蓝底大号分类按钮维护态。验证：在窄屏和常见手机宽度截图检查层级、触达与文字换行。边界：不复制官网的车型头图、营销 hero、漂浮卡片、装饰渐变或自动轮播到任务型安装界面。
