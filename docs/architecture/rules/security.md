# 安全规则

1. 触发条件：新增权限、ADB 命令、无障碍入口或文件访问。动作：记录用户价值、Android 版本边界、最小权限、拒绝后的功能退化和运行级验证。验证：Manifest / runtime 权限审查与拒绝 smoke。边界：不加入与安装助手无关的高风险权限。
2. 触发条件：下载组件 ZIP、解压或安装外部 APK。动作：只接受 HTTPS 和固定可信清单，分别校验 ZIP 与 APK 的大小和哈希，并校验唯一 entry、包名、签名证书摘要和版本；失败即停止并清理无效文件。验证：篡改、异常归档、回滚、错误签名和中断恢复 fixture。边界：不执行下载内容携带的脚本或任意命令。
3. 触发条件：保存设备或用户诊断信息。动作：最小化采集、脱敏、短期保存并由用户主动导出；日志只记录阶段、错误类别和非敏感标识。验证：日志扫描和导出内容审查。边界：不上传媒体、通讯录、完整 shell 历史或私钥。
4. 触发条件：签名、密钥、生产配置或发布身份变更。动作：先取得用户明确授权，使用独立密钥存储和可审计配置；构建前后扫描秘密。验证：证书摘要、落包配置和秘密扫描。边界：不把 debug 身份当 production 信任根。
