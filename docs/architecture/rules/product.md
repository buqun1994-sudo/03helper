# 产品规则

1. 触发条件：新增安装流程能力。动作：先说明目标用户、触发场景、用户可观察结果和失败后的下一步，再确定功能范围。验证：需求条目能映射到可执行验收。边界：不把实现便利或开发者工具自动升级为用户需求。
2. 触发条件：出现多个可选方案。动作：记录成本、网络、隐私、可回滚性和长期维护取舍，选定单一主链并记录备用链。验证：决策文档和失败切换路径。边界：不同时维护两套互相矛盾的默认流程。
3. 触发条件：涉及 03 歌词、03桌面或第三方组件。动作：以组件包身份、签名、兼容范围和用户授权为边界；安装助手只编排，不复制其业务逻辑。验证：包清单和安装结果报告。边界：不承诺未经验证的车机能力、网盘直链或自动授权。
4. 触发条件：新增破坏性动作。动作：默认关闭、二次确认、列出影响并提供可恢复路径。验证：取消和误触 smoke。边界：维护态不能把卸载、清数据或恢复出厂包装成“加速”。
