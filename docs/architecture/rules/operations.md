# 运维规则

1. 触发条件：需要本机构建、ADB 或设备验证。动作：先读取 `.codex/local-context.properties`，再执行环境检查；脚本参数必须显式指定目标设备。验证：环境快检和定向设备列表。边界：不猜测个人路径，不枚举全部在线设备执行破坏性任务。
2. 触发条件：准备安装、覆盖安装或卸载。动作：先读取目标包、版本、签名和设备状态；普通收尾只允许保留数据覆盖安装。验证：安装输出、包身份和进程 / 日志。边界：清数据、降级、卸载、重启和 release 安装需当次授权。
3. 触发条件：准备发布或切换下载源。动作：先生成一次单组件 ZIP 并镜像同一字节文件，版本清单分别记录 ZIP / APK 哈希、大小、签名摘要、兼容范围和回滚指针，再做小范围验证。验证：隐藏 WebView 下载回调、ZIP 解压、APK 校验、回滚和缓存命中。边界：不把个人存储、密码文件夹、合并 ZIP 或未审查镜像当自动正式源。
4. 触发条件：脚本失败。动作：保留失败证据并定位真实根因，禁止删断言、静默重试或扩大权限换取通过。验证：修复后重跑直接相关检查。边界：外部网络不稳定必须与确定性测试分离。
